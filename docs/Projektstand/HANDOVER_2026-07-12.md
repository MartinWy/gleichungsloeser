## Architektur

Die Arbeitsarchitektur ist inzwischen stabil:

```text
Input-Adapter -> Rechenkern P1-P3 -> Projektionskern P4 -> Renderkern/LaTeX -> Peripherie/UI
```

Kurzfassung:

- Input-Adapter: uebersetzt verschiedene Eingabeformen in kanonische Kernsyntax.
- Rechenkern P1-P3: entscheidet mathematisch und baut semantisch um.
- Projektionskern P4: erzeugt die horizontalen Orte, Spalten, Rollen und Spans.
- Renderkern/LaTeX: setzt mathematische Boxen, Brueche, Wurzeln, Potenzen und vertikale Achsen.
- Peripherie/UI: zeigt das Ergebnis im Browser, als PDF, spaeter ggf. als Film.

Zentraler Merksatz:

```text
Der Rechenkern entscheidet.
Der Projektionskern verankert.
Der Renderkern setzt.
Die Peripherie zeigt.
```

## Wichtigste Erkenntnis beim Rendering

LaTeX allein reicht nicht. Eine normale Formel wie `\frac{5-3}{a}` ist mathematisch korrekt, aber LaTeX zieht die inneren Abstaende selbst zusammen. Dadurch geht P4-Spaltentreue verloren.

Der tragfaehige Ansatz ist:

```text
P4 bestimmt den Ort.
LaTeX setzt die mathematische Schale.
Feste P4-Zellen erhalten die inneren Orte innerhalb der Schale.
```

Beispielprinzip:

```latex
\frac{
  \pFourCell{5}\pFourCell{-}\pFourCell{3}
}{
  \pFourCell{}\pFourCell{a}\pFourCell{}
}
```

Die naechste Renderstufe ist eine physische Spaltenkarte:

```text
P4-Spalten bleiben semantisch erhalten.
Papierbreiten werden am Ende aus sichtbarem Bedarf berechnet.
Nie sichtbare Hilfsspalten duerfen auf 0 kollabieren.
```

## Wichtige technische Entscheidungen

### 1. Produkt-Schalen duerfen keine Einzelbox sein

Eine erzeugte Multiplikation wie `(\frac{5}{2})^2(2+1)` darf nicht als eine breite Box in einer einzigen P4-Spalte landen. Sonst wird diese Gesamtbox zentriert und laeuft optisch nach links ueber das Gleichheitszeichen.

Aktueller Vertrag:

```text
product_content auf col 9
product_operator optional eigene Spalte
product_factor rechts daneben
```

Wenn der Malpunkt studentisch unsichtbar ist, wird keine Operator-Spalte sichtbar. Wenn er sichtbar noetig ist, bekommt er eine eigene Spalte.

### 2. Schalen-Tinte zaehlt zur Breite

Nicht nur Atome brauchen Raum, sondern auch Klammern, Wurzelhaken, Bruchstriche, Potenzklammern und Randreserven. Sonst sind die P4-Spalten logisch korrekt, aber die gedruckte Tinte laeuft in Nachbarspalten.

### 3. Verschachtelte Brueche behalten ihre Groesse

LaTeX darf `\frac{5}{2}` nicht kleiner setzen, nur weil der Bruch spaeter in einer Potenz steht. Derselbe P4-Ausdruck muss seine Projektionsgroesse behalten.

### 4. Diagnose und Reinschrift muessen dieselben Koordinaten nutzen

Die Rasterseite ist nur ein Overlay. Sie darf nicht eine andere Wahrheit zeigen als die Reinschrift.
