# Tests

Dieses Folgeprojekt sollte eigene Tests bekommen.

Die Tests pruefen nicht Algebra,
sondern Uebergangsregeln,
zum Beispiel:

- Identitaet derselben Inhalte vor und nach dem Uebergang
- monotone Kameraphasen
- keine verlorenen Atome
- stabile Zielzuordnung
- keine Rueckwirkung auf das Ursprungssystem
