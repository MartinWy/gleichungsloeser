# adapters

Hier liegen die expliziten, einseitigen Adapter des Nutzer-Cockpits.

Aktiv ist:

- `theory_labels/`: genau ein kanonischer Theorieknoten wird in eine reine
  Diagnosebeschriftung fuer Cockpit-Regler uebersetzt.

Die fuehrende Richtlinie dafuer ist `THEORY_LABEL_CONTRACT.md`.
Der Adapter erzeugt keine Renderzellen und keine Geometrie.
